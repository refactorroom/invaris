# Invaris v0.5.2

`invaris init` now explains that the `version` inside the generated JSON identifies the harness format. Run `invaris --version` to see the CLI release. New guard harnesses continue to use `invaris.dev/v1alpha2`.

If `invaris doctor` finds a `v1alpha1` harness, it shows how to preview and apply a migration. Existing harnesses remain readable, and the warning does not change the exit status.

The repository self-check now scans the same directory scope as `gofmt -l .` and consumes structured Go test results for mutation experiments. Its deliberate missed-detection controls still cause the strict campaign to reject; see the [self-check record](../experiments/self-check.md).

See the [authoring guide](../authoring.md) for setup and migration, or the [harness reference](../harness-spec.md#configuration-versions) for supported formats.
