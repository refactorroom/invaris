# Invaris v0.5.3

`invaris init` warns when Git ignores the newly created `.invaris/invaris.json`. `invaris doctor` reports the selected harness, explains discovery, and identifies whether Git tracks or ignores it. When both default harnesses exist, automatic discovery selects the workspace file and warns about the root-level file.

Git warnings do not change exit codes. Existing root-level harnesses remain supported, and doctor reports when Git status cannot be determined. Doctor runs read-only Git queries and does not run harness commands.

Commit a harness that defines project policy so teammates and CI receive it. The [sharing guide](../authoring.md#share-a-project-harness-through-git) explains how to allow the default location when a parent directory is ignored. See [doctor diagnostics](../diagnostics.md#doctor-inspect-harness-setup) for details.
