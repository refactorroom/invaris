Quick start

Install the CLI

Use npm on Linux or macOS with Node.js 22.14+. On Windows, use WSL.

Check the CLI and preview a config
npx --yes --package=invaris-cli@latest invaris --version
npx --yes --package=invaris-cli@latest invaris init --dry-run

The version in the JSON is the harness format. CLI releases can share the same format.

Install for a project or download an archive

Run a guard challenge

With Go 1.27.4+ and a POSIX shell, run the bundled structured example from a checkout.

Run the structured example
git clone https://github.com/refactorroom/invaris.git
cd invaris
go run ./cmd/invaris challenge --format text examples/v1alpha2/invaris.json

PROVEN means the guard detected the expected finding on the changed file.
